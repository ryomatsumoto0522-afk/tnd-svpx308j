原題: API キーをコマンド引数に書くと別ユーザーの ps から丸見え：curl -H は隠れず -u だけ隠れる（実機確認）

出典: Qiita（AI） · 2026-11-08

  • コマンド引数にAPIキーを直接書くと、psコマンドにより同一マシンの別ユーザーから丸見えになる。
  • curlの-H指定や--api-keyは露出する一方、環境変数は他ユーザーから閲覧不可だった。
  • 対策として、curlは-H @ファイル形式で渡すか、環境変数やファイルから読み込むことが推奨される。

影響Linuxサーバーでツールを扱う開発者は、APIキーを引数に書かずファイル等から渡す運用を確認する必要がある。
