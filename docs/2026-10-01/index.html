Cursor Uses S3 WAL to Scale Git Storage to More than 300 Pushes per Second

出典: InfoQ · 2026-09-30

Cursorは、S3を基盤とした先行書き込みログ（WAL）を信頼できる唯一の情報源として活用するGitストレージ設計「Continuity」を開発しました。従来のレプリカ間の同期間調整を不要にすることで、S3 Express One Zone利用時に毎秒300回以上のプッシュと最大100レプリカへの線形読み取りスケーリングを実現したと報告しています。この設計は、負荷の高いCI処理を抱える大規模リポジトリやAIコーディングエージェントによる多数のリポジトリ管理の効率化につながります。

Amazon Aurora PostgreSQL now supports direct querying of Apache Iceberg and Parquet data in your data lake

出典: AWS News Blog · 2026-10-01

Amazon Aurora PostgreSQLにおいて、データレイク内のApache IcebergやParquet形式のデータを直接クエリできる新機能が発表されました。組み込まれたDuckDBにより、データを複製するETL処理を行わずに、運用データとデータレイクのデータを単一のクエリで結合して分析できます。これにより運用の複雑さが低減され、バージョン17（17.11以降）や18（18.6以降）で既存ツールを用いた分析やAI開発が容易になります。

用語メモ（3）
Apache Iceberg
大規模な分析データを効率的かつ安全に管理するためのオープンソースのテーブル形式です。
ETL
データを抽出（Extract）、変換（Transform）、格納（Load）する一連のデータ統合処理です。
データレイク
様々な形式の大規模なデータを、加工を行わずにそのまま集約して保管するストレージ基盤です。
